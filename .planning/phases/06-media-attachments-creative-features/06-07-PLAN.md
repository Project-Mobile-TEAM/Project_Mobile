<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User long-press -> `MessageTranslationManager` | User might invoke translation on non-TEXT messages, on cellular data (~30MB unexpected data cost), or switch accounts while a ~30MB download is finishing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-21 | Information Disclosure (Cross-Account Cache Pollution) | `MessageTranslationManager` | medium | mitigate | Check `session.runIfCurrent(capturedSessionKey, ...)` before inserting `MessageTranslationEntity` into Room after async model download/translation; `Injection.cleanupDepartingSession` wipes `message_translation` via `clearAllTables`. |
| T-06-22 | Denial of Service / Resource Drain | `MessageTranslationManager`, `RealMlKitTranslator` | low | mitigate | Gate ~30MB cellular model downloads behind explicit `NEEDS_CELLULAR_CONFIRMATION` user approval; close `Translator` instances properly via `close()` to prevent native ML Kit leaks. |
</threat_model>

1. Create `MessageTranslationManager.java`:
   - Define `NetworkState` enum (`OFFLINE`, `WIFI_UNMETERED`, `CELLULAR_METERED`) and `public interface NetworkChecker { NetworkState currentState(); }`.
   - Provide `public static NetworkChecker fromConnectivityManager(@Nullable ConnectivityManager cm)` (inspecting `cm != null ? cm.getActiveNetwork() : null` + `cm.getNetworkCapabilities(network)` checking `NET_CAPABILITY_INTERNET` -> `OFFLINE` if absent, and `NET_CAPABILITY_NOT_METERED` -> `WIFI_UNMETERED` vs `CELLULAR_METERED`, handling null/missing network safely).
   - Provide **BOTH** constructors (`WRN-10`):
     - Primary JVM-testable constructor: `public MessageTranslationManager(@NonNull TranslationDao translationDao, @NonNull MessageTranslator translator, @NonNull NetworkChecker networkChecker, @NonNull SessionManager session, @NonNull Executor diskExecutor, @NonNull Executor mainExecutor)`
     - Convenience Android constructor matching `06-08` `Injection.java` wiring: `public MessageTranslationManager(@NonNull TranslationDao translationDao, @NonNull MessageTranslator translator, @Nullable ConnectivityManager connectivityManager, @NonNull SessionManager session, @NonNull Executor diskExecutor, @NonNull Executor mainExecutor)` delegating to `this(translationDao, translator, fromConnectivityManager(connectivityManager), session, diskExecutor, mainExecutor)`.
   - Define `TranslationStatus`: `NEEDS_CELLULAR_CONFIRMATION`, `DOWNLOADING_MODEL` (**explicitly no progress % field** per `D-15`!), `TRANSLATED` (with `translatedText` and `targetLang`), `ERROR` (with `errorCode` e.g. `UNSUPPORTED_TYPE`, `OFFLINE`, `DOWNLOAD_FAILED`).
   - `translateMessage(MessageEntity message, String targetLang, boolean cellularConfirmed, Callback)`:
     - **Enforce `TEXT`-only (`D-14`):** if `message == null || !"TEXT".equals(message.getType()) || message.getText() == null || message.getText().trim().isEmpty()`, invoke `ERROR("UNSUPPORTED_TYPE")` immediately.
     - Determine direct direction (`D-13`): if `targetLang == "vi"`, `sourceLang = "en"`; if `targetLang == "en"`, `sourceLang = "vi"`; else `ERROR("UNSUPPORTED_TYPE")`.
     - Capture `sessionKey = session.sessionKey()`.
     - Run Room cache lookup on `diskExecutor`: `MessageTranslationEntity cached = translationDao.findSync(message.getClientId(), targetLang)`.
       - **Cache hit:** return `TRANSLATED` immediately via `mainExecutor` — works 100% offline (`D-14`)!
     - **Cache miss:** check `translator.isModelDownloaded(targetLang)` and `translator.isModelDownloaded(sourceLang)`:
       - If both downloaded -> translate directly on-device (works 100% offline!), save into `translationDao.insert(...)` inside `session.runIfCurrent(sessionKey, ...)` on `diskExecutor`, emit `TRANSLATED` via `mainExecutor`.
       - If missing model(s): check `networkChecker.currentState()`:
         - `OFFLINE` -> emit `ERROR("OFFLINE")` (original message remains untouched for retry, `D-15`).
         - `CELLULAR_METERED` and `!cellularConfirmed` -> emit `NEEDS_CELLULAR_CONFIRMATION` (`D-15` asks user before downloading ~30MB!).
         - `WIFI_UNMETERED` or (`CELLULAR_METERED` &amp;&amp; `cellularConfirmed`) -> emit `DOWNLOADING_MODEL` (indeterminate, NO %), download missing model(s) -> on failure emit `ERROR("DOWNLOAD_FAILED")`; on success translate, persist to Room under `session.runIfCurrent(sessionKey, ...)`, and emit `TRANSLATED`!

2. Create `app/src/test/java/com/utechat/data/translate/MessageTranslationManagerTest.java` (100% Java 17, JUnit 4 + Mockito + `InstantTaskExecutorRule`, `Runnable::run` executors):
   - `rejectsSystemCallAndMediaMessagesWithoutCallingTranslator` (`D-14`).
   - `cacheHitReturnsSavedTranslationOfflineWithoutInvokingMlKit` (`D-14`).
   - `cellularPromptsConfirmationBeforeDownloadingAndDownloadsAfterConfirm` (`D-15`): verifies `NEEDS_CELLULAR_CONFIRMATION` when metered &amp; unconfirmed; after confirm emits `DOWNLOADING_MODEL` -> `TRANSLATED` and persists `MessageTranslationEntity`.
   - `wifiAutoDownloadsWithIndeterminateStateAndSavesRoomCache` (`D-15`): verifies no confirmation prompt on Wi-Fi, emits `DOWNLOADING_MODEL`, then `TRANSLATED`, and subsequent lookup works `OFFLINE`.
   - `offlineOrDownloadFailurePreservesOriginalAndAllowsRetry` (`D-15`): verifies `OFFLINE` / `DOWNLOAD_FAILED` never pollutes Room cache and succeeds on retry when Wi-Fi returns.
   - `ignoresDelayedResultAfterSessionSwitch`: if `sessionKey` changed mid-download, `translationDao.insert` is never called.
