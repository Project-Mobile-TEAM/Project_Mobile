<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External Apps <-> `FileProvider` (`file_paths.xml`) | Sharing downloaded documents/videos with external viewer apps must expose ONLY scoped cache/pending subdirectories, never Room DB or Keystore files. |
| Room v2 -> v3 Migration (`utechat.db`) | Existing Phase 5 user messages, FTS4 index, and `message_translation` rows must survive upgrade intact without data loss or `IllegalStateException`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-09 | Information Disclosure | `res/xml/file_paths.xml`, `AndroidManifest.xml` | high | mitigate | Set `FileProvider android:exported="false"`, `android:grantUriPermissions="true"`, and restrict `file_paths.xml` exclusively to `pending_media/`, `media_cache/`, and `camera/`; omit broad storage permissions (`READ_MEDIA_*`, `READ_EXTERNAL_STORAGE`). |
| T-06-10 | Tampering / Data Loss | `AppDatabase.MIGRATION_2_3`, `AttachmentTransferEntity` | high | mitigate | Implement explicit forward `Migration(2, 3)` with matching `@ColumnInfo(defaultValue = ...)` annotations (`'UPLOAD'`, `0`), zero `fallbackToDestructiveMigration()`, and verify via `MigrationTestHelper` (`1->2->3`, `2->3`). |
| T-06-11 | Availability / Build Integrity | `libs.versions.toml`, `rules.keep` | medium | mitigate | Pin `androidx.core:core:1.17.0` (`compileSdk = 36`), `annotationProcessor` for Glide &amp; Room (no Kapt/KSP), and add R8 keep rules for `org.webrtc.**`, `com.google.mlkit.**`, and `@GlideModule`. |
</threat_model>
