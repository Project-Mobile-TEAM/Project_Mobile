<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Photo Picker / SAF `content://` URI -> `MediaPreparationHelper` | Untrusted external document URIs may have huge dimensions (OOM), >50MB size, disallowed MIME, or path-traversal display names. |
| `SendMessageWorker` -> Local Disk &amp; Network (`POST /media`, `POST /messages`) | Mid-flight network drop or session switch (`401`/logout) could orphan temp files, duplicate server uploads, or write into a new user's Room DB. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-12 | Tampering / Information Disclosure | `MediaPreparationHelper`, `MediaDownloadManager` | high | mitigate | Decode image bounds first (`inJustDecodeBounds`), scale via `inSampleSize` + EXIF rotation (`ExifInterface`), re-encode JPEG (strips EXIF GPS), sanitize downloaded filenames before writing `cacheDir/media_cache/`, and resolve `mediaUrl` strictly against `BuildConfig.BACKEND_BASE_URL` (`resolveBackendMediaUrl` validates `/api/media/...` prefix). |
| T-06-13 | Token Leak | `ApiClient.getMediaOkHttpClient`, `UteChatGlideModule`, `MediaDownloadManager` | high | mitigate | Rely on `AuthInterceptor` (`BACKEND_HOST` guard) + Release `Level.NONE`; never pass JWT to external viewer apps (download locally then share `FileProvider` `content://` URI with `FLAG_GRANT_READ_URI_PERMISSION`). |
| T-06-14 | Repudiation / Session Confusion | `SendMessageWorker.executeSend` | high | mitigate | Capture `enqueuedSessionKey`, `token`, `version` under `synchronized (session)` and gate both `markUploaded` and `markSentFromWorker` inside `session.runIfCurrent(enqueuedSessionKey, ...)`; cancel only `queueName(enqueuedSessionKey)` on `401`. |
</threat_model>
