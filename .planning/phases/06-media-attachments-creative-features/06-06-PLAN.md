<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Incoming WebSocket signaling frames -> `CallSessionCoordinator` | Stale, replayed, or mismatched `callId` `call.offer`/`answer`/`ice`/`handled_elsewhere` frames could corrupt an ongoing call or spoof audio connection. |
| `CallFragment` / `CallService` -> Android 14–16 OS Microphone Foreground Service | Calling `startForeground(FOREGROUND_SERVICE_TYPE_MICROPHONE)` without `RECORD_AUDIO` throws fatal `SecurityException` on `targetSdk = 36`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-18 | Spoofing / Tampering | `CallSessionCoordinator` | high | mitigate | Drop `call.offer`, `call.answer`, `call.ice`, `call.accepted`, `call.ended`, `call.handled_elsewhere` whenever `callId` does not match active call or `sessionKey` changed; reject second incoming call locally if already in non-`IDLE` call. |
| T-06-19 | Availability (Android 14+ FGS Crash) | `CallService`, `CallFragment` | high | mitigate | Verify `ContextCompat.checkSelfPermission(RECORD_AUDIO) == GRANTED` before starting `CallService` foreground microphone; ring via `RingtoneManager` + `Vibrator` first on `call.incoming`, and only start `CallService` after `RECORD_AUDIO` is granted on outgoing/accept. |
| T-06-20 | Information Disclosure | `CallSessionCoordinator.onSessionCleared`, `StreamWebRtcCallEngine.close` | medium | mitigate | On logout/401/4401 or call end, release `PeerConnectionFactory`/audio focus/ringtone immediately and wipe active caller UI state. |
</threat_model>
