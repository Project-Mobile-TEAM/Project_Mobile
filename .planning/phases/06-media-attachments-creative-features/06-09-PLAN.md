<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `ChatRoomFragment` / `MessageAdapter` -> External Intent Handlers (`geo:`, `ACTION_VIEW` `FileProvider`) | Device may have no Maps/document viewer app installed (`ActivityNotFoundException`), or `attachmentJson` could be malformed. |
| `ChatRoomFragment` -> Runtime Android Permissions (`CAMERA`, `RECORD_AUDIO`, `ACCESS_FINE_LOCATION`) | User may deny permissions; UI must handle denial cleanly without crashing or looping permission prompts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-25 | Denial of Service (UI Crash) | `ChatRoomFragment`, `VideoPlayerFragment`, `MessageAdapter` | medium | mitigate | Wrap external `Intent.ACTION_VIEW` (`geo:` and `FileProvider`) calls in `try { startActivity(...) } catch (ActivityNotFoundException)` showing friendly Snackbar; parse `attachmentJson` defensively with fallback labels; release `ExoPlayer` and `VoiceBubblePlayer` in `onStop`/`onDestroyView`. |
| T-06-26 | Information Disclosure (Camera / Temp Files) | `ChatRoomFragment` | low | mitigate | Write camera capture outputs strictly to `cacheDir/camera/` via `FileProvider`, compress/strip EXIF via `MediaPreparationHelper` into `pending_media/`, and delete raw camera capture immediately afterward. |
</threat_model>
