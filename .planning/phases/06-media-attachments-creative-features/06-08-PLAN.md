<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Departing Session -> New Session (`Injection.cleanupDepartingSession`) | Pending media uploads, downloaded `media_cache` files, active WebRTC calls, OS notifications, or `SyncWorker` schedules from Account A must never bleed into Account B. |
| Notification `Intent` -> `MainActivity` | Notification deep-link extras arriving before authentication completes must not bypass `SplashFragment` / `nav_auth` gate. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-23 | Information Disclosure | `Injection.cleanupDepartingSession`, `RealChatRepository.deleteFailedMessage` | high | mitigate | Cancel `SendMessageWorker.queueName(key)` &amp; `SyncWorker.queueName(key)`, disconnect WS, invoke `CallSessionCoordinator.onSessionCleared()`, clear `NotificationHelper.cancelAll()`, and recursively delete `pending_media/`, `media_cache/`, `camera/` on `DISK`. |
| T-06-24 | Elevation of Privilege (Auth Bypass via Notification Tap) | `MainActivity` | high | mitigate | Check the originating session at consumption and after membership resolution. Route only from an authenticated destination and discard stale chat or call IDs. |
</threat_model>
