# Plan 02-02: Android Room SQLite v1 13 Entities & Seam Fake Repos

## Mục tiêu
Triển khai Hotspot 5 và Hotspot 6 của Kiến trúc chống xung đột: Khóa chết lược đồ Room SQLite v1 bằng cách định nghĩa đầy đủ 13 Entity ánh xạ chính xác từ `docs/ERD.md` kèm bộ chuyển đổi kiểu dữ liệu `Converters.java`, DAOs và Singleton `AppDatabase.java`. Thiết lập kiến trúc Seam với 3 Interface trừu tượng (`AuthRepository`, `ContactsRepository`, `ChatRepository`), triển khai 3 Fake Repositories nạp sẵn dữ liệu 5 tài khoản demo từ Phase 1, và điều phối qua Service Locator `Injection.java` cùng `ViewModelFactory.java` chuẩn slide bài giảng, bảo đảm 100% unit tests pass trên JVM.

<action>
1. Tạo tệp `app/src/main/java/com/utechat/data/local/Converters.java`:
   - `@TypeConverter` cho `Date <-> Long` (timestamp mili-giây).
   - `@TypeConverter` cho `UUID <-> String`.
   - `@TypeConverter` cho `List<String> <-> String` (sử dụng Gson serialization).
   - Chú thích Tiếng Việt giải thích bản chất lưu trữ của SQLite (chỉ hỗ trợ kiểu nguyên thủy).

2. Tạo đầy đủ 13 Room Entity trong gói `com.utechat.data.local.entity`:
   - `UserEntity`: Bảng `users`, `@PrimaryKey @NonNull String id`, `phone_e164` (unique index), `display_name`, `avatar_url`, `password_hash`, `allow_messages_from_non_contacts`, `status`, `created_at`.
   - `UserDeviceEntity`: Bảng `user_devices`, `@PrimaryKey @NonNull String id`, `user_id`, `device_id_hash`, index `(user_id, device_id_hash)`, `device_name`, `platform`, `token_valid_after`.
   - `OtpChallengeEntity`: Bảng `otp_challenges`, `@PrimaryKey @NonNull String id`, `phone_e164`, `purpose`, `code_hash`, `attempts`, `expires_at`.
   - `AuthSessionEntity`: Bảng `auth_sessions`, `@PrimaryKey @NonNull String id`, `user_id`, `device_id_hash`, `method`, `state`, `expires_at`.
   - `AuthThrottleEntity`: Bảng `auth_throttles`, `@PrimaryKey @NonNull String id`, `scope_type`, `scope_key_hash`, `purpose`, unique index `(scope_type, scope_key_hash, purpose)`, `failure_count`, `locked_until`.
   - `ContactRequestEntity`: Bảng `contact_requests`, `@PrimaryKey @NonNull String id`, `requester_id`, `addressee_id`, `status` (PENDING, ACCEPTED, REJECTED, CANCELED), `created_at`.
   - `ContactEntity`: Bảng `contacts`, khóa chính kết hợp `primaryKeys = {"owner_id", "contact_user_id"}`, `blocked` (boolean: false = bạn bè, true = đã chặn), index `(owner_id, blocked)`.
   - `ConversationEntity`: Bảng `conversations`, `@PrimaryKey @NonNull String id`, `type` (DIRECT/GROUP), `title`, `avatar_url`, `direct_key` (unique index), `last_message_id`.
   - `ConversationMemberEntity`: Bảng `conversation_members`, khóa chính kết hợp `primaryKeys = {"conversation_id", "user_id"}`, `role`, `last_delivered_message_id`, `last_read_message_id`.
   - `MessageEntity`: Bảng `messages`, `@PrimaryKey(autoGenerate = true) Long id`, `conversation_id`, `sender_id`, `client_id` (unique index sender_id + client_id), `type`, `text`, `status` (SENDING, SENT, DELIVERED, READ, FAILED), index `(conversation_id, id DESC)`.
   - `AttachmentEntity`: Bảng `attachments`, `@PrimaryKey @NonNull String id`, `uploader_id`, `kind`, `mime`, `size_bytes`, `storage_path`, `duration_ms`.
   - `CallEntity`: Bảng `calls`, `@PrimaryKey @NonNull String id`, `conversation_id`, `caller_id`, `callee_id`, `media`, `state`, `started_at`, `ended_at`.
   - `SyncEventEntity`: Bảng `sync_events`, `@PrimaryKey Long id`, `user_id`, `event_type`, `entity_type`, `entity_id`, `payload_json`, index `(user_id, id)`.
   - Mọi Entity đều có Constructor, Getters, Setters đầy đủ kèm chú thích Tiếng Việt từng trường.

3. Tạo các Interface DAO cơ bản trong `com.utechat.data.local.dao`:
   - `UserDao`: `@Insert(onConflict = OnConflictStrategy.REPLACE) void insert(UserEntity user)`, `@Query("SELECT * FROM users WHERE id = :id") LiveData<UserEntity> getUserById(String id)`, `@Query("SELECT * FROM users WHERE phone_e164 = :phone") LiveData<UserEntity> getUserByPhone(String phone)`.
   - `ContactDao`: `@Insert(onConflict = OnConflictStrategy.REPLACE) void insert(ContactEntity contact)`, `@Query("SELECT * FROM contacts WHERE owner_id = :ownerId AND blocked = 0") LiveData<List<ContactEntity>> getFriends(String ownerId)`, `@Query("SELECT * FROM contacts WHERE owner_id = :ownerId AND blocked = 1") LiveData<List<ContactEntity>> getBlockedContacts(String ownerId)`.
   - `ConversationDao`: `@Insert(onConflict = OnConflictStrategy.REPLACE) void insert(ConversationEntity conversation)`, `@Query("SELECT * FROM conversations ORDER BY last_message_id DESC") LiveData<List<ConversationEntity>> getAllConversations()`.
   - `MessageDao`: `@Insert(onConflict = OnConflictStrategy.REPLACE) long insert(MessageEntity message)`, `@Query("SELECT * FROM messages WHERE conversation_id = :conversationId ORDER BY id ASC") LiveData<List<MessageEntity>> getMessagesForConversation(String conversationId)`.
   - `SyncEventDao`: `@Insert(onConflict = OnConflictStrategy.REPLACE) void insert(SyncEventEntity event)`, `@Query("SELECT * FROM sync_events WHERE user_id = :userId AND id > :afterId ORDER BY id ASC") List<SyncEventEntity> getEventsAfter(String userId, long afterId)`.

4. Tạo Singleton CSDL `app/src/main/java/com/utechat/data/local/AppDatabase.java`:
   - Kế thừa `RoomDatabase`, `@Database(entities = {13 lớp entity}, version = 1, exportSchema = true)`.
   - `@TypeConverters({Converters.class})`.
   - Triển khai Singleton an toàn đa luồng (Double-Checked Locking).
   - Bật `.fallbackToDestructiveMigration()` trong giai đoạn dev (ADR-020).

5. Tạo unit test `app/src/test/java/com/utechat/data/local/RoomConvertersTest.java`:
