# Plan 02-01: Backend Spring Boot 3 & Supabase Pooler Ping

## Mục tiêu
Xây dựng dự án máy chủ Spring Boot 3 độc lập bên trong thư mục `backend/` sử dụng Apache Maven và Java 17 LTS. Cấu hình kết nối cơ sở dữ liệu Supabase PostgreSQL qua Transaction Pooler (cổng 6543, `prepareThreshold=0`, HikariCP) nạp tự động từ `.env` qua `dotenv-java`, hỗ trợ CORS toàn diện cho môi trường dev/Android emulator, và triển khai các REST endpoint `GET /api/health`, `GET /api/health/ready` thực hiện truy vấn ping thật `SELECT 1` kèm bộ kiểm thử tự động MockMvc đạt pass 100%.

<action>
1. Tạo tệp `backend/pom.xml` cấu hình dự án Maven chuẩn Java 17 LTS:
   - Kế thừa `spring-boot-starter-parent` phiên bản `3.3.5`.
   - `groupId`: `com.utechat`, `artifactId`: `backend`, `version`: `1.0.0`.
   - Thuộc tính `java.version`: `17`, mã hóa UTF-8.
   - Các dependencies: `spring-boot-starter-web`, `spring-boot-starter-jdbc`, `org.postgresql:postgresql` (runtime), `io.github.cdimascio:dotenv-java:3.1.0`, và `spring-boot-starter-test` (test).
   - Plugin: `spring-boot-maven-plugin`.

2. Tạo cấu hình ứng dụng trong `backend/src/main/resources/`:
   - `application.yml`: Thiết lập `server.port: 8080`, kích hoạt profile `spring.profiles.active: dev`, cấu hình logging mức `INFO` chung và `DEBUG` cho gói `com.utechat.backend`.
   - `application-dev.yml`: Cấu hình DataSource kết nối Supabase PostgreSQL:
     ```yaml
     server:
       port: 8080
     spring:
       datasource:
         url: ${SPRING_DATASOURCE_URL:jdbc:postgresql://localhost:6543/postgres?sslmode=require&prepareThreshold=0}
         username: ${SPRING_DATASOURCE_USERNAME:postgres}
         password: ${SPRING_DATASOURCE_PASSWORD:}
         driver-class-name: org.postgresql.Driver
         hikari:
           pool-name: UTEChat-HikariCP
           maximum-pool-size: 5
           minimum-idle: 1
           idle-timeout: 300000
           max-lifetime: 600000
           connection-timeout: 15000
           connection-test-query: SELECT 1
     ```
     > [!IMPORTANT]
     > Tham số `prepareThreshold=0` trong JDBC URL là BẮT BUỘC để ngăn ngừa lỗi `prepared statement "S_1" does not exist` khi đi qua Transaction Pooler cổng 6543 của PgBouncer.

3. Tạo lớp khởi chạy chính `backend/src/main/java/com/utechat/backend/BackendApplication.java`:
   - Kiểm tra và nạp tệp `.env` từ thư mục hiện tại (`.`) hoặc thư mục cha (`..`) bằng `Dotenv.configure()`.
   - Đẩy toàn bộ các cặp key-value từ `.env` vào `System.setProperty()` trước khi gọi `SpringApplication.run(BackendApplication.class, args)`.
   - Đảm bảo chú thích Tiếng Việt rõ ràng trên từng phương thức và khối lệnh xử lý.

4. Tạo lớp cấu hình CORS `backend/src/main/java/com/utechat/backend/config/CorsConfig.java`:
   - Đăng ký `WebMvcConfigurer` cho phép mọi nguồn gốc (`allowedOriginPatterns("*")`), mọi phương thức (`GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `OPTIONS`), và mọi headers để Android Emulator (`10.0.2.2`) và các thiết bị LAN kết nối mượt mà trong giai đoạn phát triển.
   - Thêm chú thích Tiếng Việt giải thích mục đích bảo mật và môi trường dev.
</action>

<action>
1. Tạo lớp DTO `backend/src/main/java/com/utechat/backend/dto/HealthResponse.java`:
   - Các trường dữ liệu: `private String status;` (UP / DOWN), `private String database;` (CONNECTED / DISCONNECTED / UNEXPECTED_RESPONSE), `private String timestamp;` (chuỗi ISO-8601).
   - Constructor đầy đủ, getters, setters.
   - Thêm chú thích Tiếng Việt giải thích cấu trúc phản hồi JSON tương thích với Walking Skeleton Probe phía Android.

2. Tạo REST Controller `backend/src/main/java/com/utechat/backend/controller/HealthController.java`:
   - `@RestController`, `@RequestMapping("/api")`.
   - Tiêm phụ thuộc `JdbcTemplate` qua constructor.
   - Endpoint `GET /api/health`:
     - Thực thi câu lệnh `jdbcTemplate.queryForObject("SELECT 1", Integer.class)`.
     - Nếu kết quả trả về bằng 1: Trả về HTTP 200 `ResponseEntity.ok(new HealthResponse("UP", "CONNECTED", Instant.now().toString()))`.
     - Nếu kết quả khác 1: Trả về HTTP 503 `ResponseEntity.status(HttpStatus.SERVICE_UNAVAILABLE).body(new HealthResponse("DOWN", "UNEXPECTED_RESPONSE", Instant.now().toString()))`.
     - Nếu ném ra ngoại lệ (Exception kết nối mạng, pooler cạn kiệt, v.v.): Bắt lỗi và trả về HTTP 503 `ResponseEntity.status(HttpStatus.SERVICE_UNAVAILABLE).body(new HealthResponse("DOWN", "DISCONNECTED: " + e.getMessage(), Instant.now().toString()))`.
   - Endpoint `GET /api/health/ready`: Gọi lại `checkHealth()` để bảo đảm tương thích 100% với hợp đồng `API_CONTRACT.md` mục 2.0.
   - Chú thích Tiếng Việt rõ ràng từng dòng code và luồng kiểm tra lỗi.

3. Tạo bộ kiểm thử tự động MockMvc tại `backend/src/test/java/com/utechat/backend/health/HealthControllerTest.java`:
   - Sử dụng `@WebMvcTest(HealthController.class)`.
   - Tiêm `@Autowired MockMvc mockMvc` và `@MockBean JdbcTemplate jdbcTemplate`.
   - Test case 1: `testHealthCheck_WhenDatabaseUp_ReturnsHttp200()`:
     - Mockito `when(jdbcTemplate.queryForObject("SELECT 1", Integer.class)).thenReturn(1)`.
     - Thực hiện `get("/api/health")`.
     - Kỳ vọng: `status().isOk()`, `jsonPath("$.status").value("UP")`, `jsonPath("$.database").value("CONNECTED")`, `jsonPath("$.timestamp").exists()`.
   - Test case 2: `testHealthCheck_WhenDatabaseDown_ReturnsHttp503()`:
     - Mockito `when(jdbcTemplate.queryForObject("SELECT 1", Integer.class)).thenThrow(new CannotGetJdbcConnectionException("DB unreachable"))`.
     - Thực hiện `get("/api/health")`.
     - Kỳ vọng: `status().isServiceUnavailable()`, `jsonPath("$.status").value("DOWN")`, `jsonPath("$.database").value(org.hamcrest.Matchers.startsWith("DISCONNECTED"))`.
   - Chú thích Tiếng Việt giải thích mục đích kiểm thử cho từng test case.
</action>
