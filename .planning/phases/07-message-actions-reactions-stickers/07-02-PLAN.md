<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted Android client -> `StickerController` | Client supplies `packId`, `packCode`, and `fileName` path segments. Identity comes strictly from `@AuthenticationPrincipal AuthenticatedActor`. |
| `StickerService.loadAsset` -> Classpath Resources (`stickers/`) | Unvalidated path segments could attempt classpath/directory traversal (`../application.yml`). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-05 | Information Disclosure (Path Traversal / Unauthenticated Access) | `StickerController`, `StickerService.loadAsset` | high | mitigate | Keep `/api/stickers/**` under Spring Security `.anyRequest().authenticated()` (Bearer JWT required); validate `packCode` against `^[a-z0-9_-]{1,50}$` and `fileName` against `^[a-z0-9_-]{1,50}\.(png|webp)$` (`400 VALIDATION` on mismatch); load strictly from `ClassPathResource("stickers/" + packCode + "/" + fileName)` and emit `X-Content-Type-Options: nosniff`. |
| T-07-06 | Tampering (Spoofed Sticker Payload) | `MessageService.sendMessage` (`STICKER`) | medium | mitigate | Validate `stickerId` is a valid UUID existing in `public.stickers` (`404 NOT_FOUND` if missing), reject non-null `text`/`mediaUrl`/`latitude`/`longitude` (`400 VALIDATION`), and enforce all existing group/direct policies and `30/10s` rate limit. |
</threat_model>

   - Generate them via a short one-off Java `BufferedImage(256, 256, TYPE_INT_ARGB)` + `Graphics2D` (antialiased rounded badge/mascot illustration with distinct vibrant color palette, expressive vector icon shapes, and crisp Vietnamese caption banner per sticker) and verify every file starts with PNG magic bytes `89 50 4E 47 0D 0A 1A 0A` and is non-empty. Do not leave temporary generator scripts in `backend/src/main/`.

2. Create `backend/src/main/java/com/utechat/backend/dto/StickerDtos.java` (`@JsonInclude(NON_NULL)` Java 17 records):
   - `StickerDto(String id, String packId, String code, String label, String imageUrl, String mime, int width, int height, int sortOrder)`
   - `StickerPackDto(String id, String code, String name, String description, String thumbnailUrl, boolean isDefault, boolean installed, int sortOrder, List<StickerDto> stickers)`
   - `StickerAsset(byte[] bytes, String contentType)`

3. Create `backend/src/main/java/com/utechat/backend/service/StickerService.java`:
   - Inject `JdbcTemplate`.
   - `listPacks(UUID actorId)` (`@Transactional(readOnly = true)`):
     - Query `public.sticker_packs sp LEFT JOIN public.user_sticker_packs usp ON usp.pack_id = sp.id AND usp.user_id = ?` selecting `COALESCE(usp.installed, sp.is_default) AS installed` ordered by `sp.sort_order ASC, sp.code ASC`.
     - Query all rows from `public.stickers ORDER BY sort_order ASC, code ASC`, group by `pack_id`, and assemble `List<StickerPackDto>`.
   - `installPack(UUID actorId, UUID packId)` (`@Transactional`):
     - Verify `packId` exists in `public.sticker_packs` (`404 NOT_FOUND` if missing).
     - Upsert `INSERT INTO public.user_sticker_packs (user_id, pack_id, installed, installed_at) VALUES (?, ?, TRUE, now()) ON CONFLICT (user_id, pack_id) DO UPDATE SET installed = TRUE, installed_at = now()`.
   - `uninstallPack(UUID actorId, UUID packId)` (`@Transactional`):
     - Verify `packId` exists in `public.sticker_packs` (`404 NOT_FOUND` if missing).
     - Upsert `INSERT INTO public.user_sticker_packs (user_id, pack_id, installed, installed_at) VALUES (?, ?, FALSE, now()) ON CONFLICT (user_id, pack_id) DO UPDATE SET installed = FALSE`.
   - `loadAsset(String packCode, String fileName)`:
     - Validate `packCode` matches `^[a-z0-9_-]{1,50}$` and `fileName` matches `^[a-z0-9_-]{1,50}\.(png|webp)$`; if invalid, throw `ApiException(HttpStatus.BAD_REQUEST, "VALIDATION", "Invalid sticker asset path")`.
     - Read `ClassPathResource("stickers/" + packCode + "/" + fileName)`; if `!resource.exists()`, throw `404 NOT_FOUND`.
     - Return `StickerAsset(resource.getContentAsByteArray(), fileName.endsWith(".webp") ? "image/webp" : "image/png")`.

4. Create `backend/src/main/java/com/utechat/backend/controller/StickerController.java`:
   - `@RestController @RequestMapping("/api/stickers")` (automatically protected by `SecurityConfig` `.anyRequest().authenticated()`).
   - `@GetMapping("/packs")` -> `List<StickerPackDto>` (`stickerService.listPacks(actor.userId())`).
   - `@PostMapping("/packs/{packId}/install")` -> `204 No Content` (`ConversationController.parsePathUuid(packId)` -> `stickerService.installPack(...)`).
   - `@DeleteMapping("/packs/{packId}/install")` -> `204 No Content` (`stickerService.uninstallPack(...)`).
   - `@GetMapping("/assets/{packCode}/{fileName}")` -> `ResponseEntity<byte[]>` with `Content-Type`, `Content-Length`, `Cache-Control: private, max-age=86400`, and `X-Content-Type-Options: nosniff`.
