1. Extend `app/src/test/java/com/utechat/ui/chat/ChatViewModelTest.java` (preserving all existing Phase 5/6 tests):
   - Test `MessageActionBottomSheet.computeVisibility(...)`:
     - Sender's own `< 24h` `TEXT` in active unblocked chat -> `showEmojiBar=true, showTranslateVi=true, showTranslateEn=true, showRecall=true, showDeleteForMe=true`.
     - Sender's own `>= 24h` `TEXT` -> `showRecall=false`, others preserved.
     - Non-sender's `TEXT` -> `showRecall=false`, `showEmojiBar=true`, `showDeleteForMe=true`.
     - `CALL` message -> `showRecall=false`, `showTranslate*=false`, `showEmojiBar=true`, `showDeleteForMe=true`.
     - Recalled message (`recalledAt != null`) -> `showEmojiBar=false, showTranslate*=false, showRecall=false, showDeleteForMe=true`.
     - Read-only (left group) or blocked 1-1 chat -> `showEmojiBar=false, showRecall=false, showDeleteForMe=true` (`D-04`).
     - Unsent queued message (`serverId == null`) -> `showEmojiBar=false, showRecall=false, showDeleteForMe=false`.
   - Test `MessageAdapter.viewType(...)`: preserves `0..5`, maps `STICKER` outgoing -> `6` (`TYPE_STICKER_OUT`) and incoming -> `7` (`TYPE_STICKER_IN`), and routes recalled `IMAGE`/`STICKER` to `TYPE_TEXT_OUT` / `TYPE_TEXT_IN`.
   - Test `SystemMessageFormatter.preview(...)` with `recalledAt != null` -> `R.string.chat_message_recalled` and with `"STICKER"` -> `R.string.chat_type_sticker`; test `ChatErrors.message("RECALL_EXPIRED")` -> `R.string.chat_error_recall_expired`.
   - Test `ChatRoomViewModel`:
     - `observeReactionsMap()` groups reactions by `messageServerId`.
     - When `ChatRepository.recallMessage` / `deleteMessageForMe` / `toggleReaction` returns `ChatResult.error("NETWORK")`, `vm.notice` emits `R.string.chat_action_requires_network` (`D-12`).
     - `vm.sendSticker(sticker)` delegates to `ChatRepository.enqueueStickerMessage`.

   - Verify tapping an emoji adds a reaction chip below the bubble, and tapping the chip cluster opens `ReactionDetailsBottomSheet` with `R.string.chat_reactions_title`.

   - Verify recalling a message renders `R.string.chat_message_recalled`.
