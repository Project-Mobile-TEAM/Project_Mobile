<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User UI Interaction -> `MessageActionBottomSheet` / `ChatRoomViewModel` | Client-side visibility hiding (e.g., hiding Recall after 24h or for non-senders) is UX-only; server remains authoritative and UI handles `409 RECALL_EXPIRED`/`403` errors gracefully. |
| `MessageEntity.attachmentJson` -> `MessageAdapter` (Glide) | Sticker metadata JSON from DB/sync must be parsed safely with try/catch and resolved strictly through `ApiClient.resolveBackendStickerUrl` so malformed JSON never crashes RecyclerView or leaks Bearer tokens. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-13 | Denial of Service (UI Crash on Malformed JSON) | `MessageAdapter`, `SystemMessageFormatter` | low | mitigate | Guard `JsonParser.parseString` in try/catch and fall back gracefully on missing/malformed sticker metadata or recalled fields. |
| T-07-14 | Information Disclosure (Recalled Content Still Shown) | `MessageAdapter`, `ConversationListAdapter` | high | mitigate | When `message.getRecalledAt() != null`, force muted italic `R.string.chat_message_recalled`, hide media/translation/reaction views, and detach media click listeners. |
</threat_model>
