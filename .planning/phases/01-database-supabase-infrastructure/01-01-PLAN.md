# Plan 01-01: Thiết lập Cấu hình An toàn & Tài liệu Hướng dẫn Supabase

## Mục tiêu
Thiết lập cơ chế bảo mật chống rò rỉ secret key (Zero-Leakage Policy theo ADR-007), tạo tệp mẫu biến môi trường `.env.example` với đầy đủ cấu hình phân định Dual-Port (Port 5432 Session Pooler cho Flyway DDL và Port 6543 Transaction Pooler cho HikariCP với `prepareThreshold=0`), đồng thời soạn thảo tài liệu `docs/SUPABASE_SETUP.md` hướng dẫn chi tiết quy trình khởi tạo dự án Supabase, bảo mật RLS Default Deny và cách chạy migration cho cả nhóm.

<action>
1. Cập nhật tệp `.gitignore` ở thư mục gốc: bổ sung khối khai báo loại trừ toàn diện các tệp cấu hình chứa secret, đồng thời giữ ngoại lệ cho `.env.example`:

   ```gitignore
   # -----------------------------------------------------------------------------
   .env
   .env.local
   .env.*
   *.env
   !.env.example
   ```
2. Tạo tệp `.env.example` tại thư mục gốc với các placeholder an toàn (không điền mật khẩu hay service key thật), phân định rõ 2 cổng kết nối theo nghiên cứu kỹ thuật:
   - Phần 1: Supabase Project Metadata (`SUPABASE_PROJECT_ID=your-project-ref-id`, `SUPABASE_URL=https://your-project-ref-id.supabase.co`, `SUPABASE_ANON_KEY=your-supabase-anon-public-key`, `SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-secret-key`).
   - Phần 2: Session Pooler / Direct Connection (Port 5432) dành cho Flyway DDL Migrations:
     `DB_HOST=aws-0-ap-southeast-1.pooler.supabase.com`
     `DB_PORT_SESSION=5432`
     `DB_NAME=postgres`
     `DB_USER=postgres.your-project-ref-id`
     `DB_PASSWORD=your-super-secure-database-password`
     `FLYWAY_URL=jdbc:postgresql://${DB_HOST}:${DB_PORT_SESSION}/${DB_NAME}?sslmode=require`
   - Phần 3: Transaction Pooler Connection (Port 6543) dành cho Spring Boot HikariCP Runtime:
     `DB_PORT_TRANSACTION=6543`
     `SPRING_DATASOURCE_URL=jdbc:postgresql://${DB_HOST}:${DB_PORT_TRANSACTION}/${DB_NAME}?sslmode=require&prepareThreshold=0`
     `SPRING_DATASOURCE_USERNAME=${DB_USER}`
     `SPRING_DATASOURCE_PASSWORD=${DB_PASSWORD}`
   - Kèm các khối ghi chú giải thích rõ lý do cần `prepareThreshold=0` (chống lỗi prepared statement cache S_1) và lý do Flyway phải chạy trên Port 5432 (duy trì `pg_advisory_lock`).
</action>

<action>
Tạo mới tệp tài liệu `docs/SUPABASE_SETUP.md` bằng tiếng Việt chuẩn Markdown GitHub với đầy đủ các phần sau:
1. **Metadata Banner & Tham chiếu:** Trạng thái HOÀN TẤT, tham chiếu `docs/ERD.md` và `docs/ARCHITECTURE_DECISIONS.md` (ADR-007).
2. **Tổng quan mô hình kiến trúc Supabase M2 (ADR-007):**
   - Supabase chỉ đóng vai trò là CSDL PostgreSQL quản lý (managed database).
   - Server Spring Boot là nguồn sự thật duy nhất (Single Source of Truth), quản lý toàn bộ transaction và nghiệp vụ.
   - App Android tuyệt đối không gọi trực tiếp Supabase, không lưu bất kỳ Supabase key nào.
   - Sơ đồ Mermaid luồng kết nối giữa Client -> Spring Boot Backend -> Supabase (Session 5432 và Tx 6543) và chặn PostgREST.
3. **Hướng dẫn khởi tạo dự án Supabase:**
   - Chọn khu vực (Region): Singapore (`ap-southeast-1`) để đạt độ trễ mạng thấp nhất từ Việt Nam (< 50ms).
   - Đặt mật khẩu cơ sở dữ liệu mạnh (tối thiểu 16 ký tự, gồm chữ hoa, thường, số, ký tự đặc biệt).
   - Lấy chuỗi kết nối: Đi tới Settings -> Database -> Connection string (URI / JDBC).
4. **Kiến trúc phân cổng kết nối (Dual-Port Strategy):**
   - **Port 5432 (Session Mode):** Dành riêng cho Flyway DDL Migrations để giữ session state cho `pg_advisory_lock`.
   - **Port 6543 (Transaction Mode):** Dành cho ứng dụng Spring Boot HikariCP để tối ưu hàng ngàn kết nối.
   - **Cảnh báo lỗi Prepared Statement:** Bắt buộc phải thêm `prepareThreshold=0` trên Port 6543 để triệt tiêu lỗi `prepared statement "S_1" does not exist`.
5. **Cơ chế Row Level Security (RLS) & Khóa chặt PostgREST:**
   - Giải thích nguyên lý Default Deny: Khi `ENABLE ROW LEVEL SECURITY` trên tất cả 14 bảng mà không tạo policy nào, PostgREST chặn 100% truy cập từ `anon` và `authenticated`.
   - Spring Boot dùng tài khoản `postgres` có thuộc tính `BYPASSRLS` nên đọc ghi bình thường.
   - Cảnh báo cấm kỵ: Tuyệt đối KHÔNG chạy `FORCE ROW LEVEL SECURITY`.
6. **Hướng dẫn thiết lập môi trường cho lập trình viên:**
   - Cách copy `.env.example` thành `.env` trên máy cá nhân.
   - Nhắc nhở quy tắc bảo mật (Zero-Leakage Policy): Tuyệt đối không đẩy `.env` lên GitHub.
7. **Hướng dẫn thực thi Flyway Migrations:**
   - Chạy migration tự động qua Spring Boot khi khởi động backend.
   - Chạy migration độc lập bằng Flyway CLI hoặc Maven Plugin: `mvn flyway:migrate`.
   - Kiểm tra kết quả trong bảng `flyway_schema_history`.
8. **Danh sách 5 tài khoản demo chuẩn:**
   - Bảng tổng hợp Alice (`+84901111111`), Bob (`+84902222222`), Charlie (`+84903333333`), David (`+84904444444`), Eve (`+84905555555`) cùng mật khẩu chuẩn `Password123!` và vai trò kịch bản.
9. **Khắc phục sự cố thường gặp (Troubleshooting):**
   - Lỗi kết nối timeout: kiểm tra firewall mạng hoặc IPv6 pooler.
   - Lỗi `prepared statement "S_1" does not exist`: kiểm tra lại tham số `prepareThreshold=0`.
   - Lỗi `pg_advisory_lock` bị ngắt: kiểm tra xem Flyway có đang trỏ nhầm vào Port 6543 thay vì 5432 hay không.
</action>
