# Plan 01-02: Khởi tạo Migration DDL 13 Bảng Cốt lõi & Khóa PostgREST RLS

## Mục tiêu
Tạo tệp migration Flyway DDL `backend/src/main/resources/db/migration/V1__initial_schema.sql` định nghĩa chuẩn xác đúng 13 bảng thuộc phạm vi V1 và 1 bảng phụ trợ demo theo tài liệu thiết kế tối cao `docs/ERD.md`, cài đặt toàn bộ khóa ngoại kèm hành vi cascade/set null, thiết lập ràng buộc CHECK, chỉ mục hiệu năng cao (đặc biệt là partial unique index chống trùng lời mời kết bạn ngược chiều và composite index phân trang tin nhắn), đồng thời kích hoạt Row Level Security (RLS) trên 100% các bảng mà không tạo policy nào nhằm khóa hoàn toàn cổng PostgREST theo ADR-007.

4. Viết các câu lệnh `CREATE TABLE` theo thứ tự DAG phụ thuộc để tránh xung đột foreign key:
   - **`users`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `phone_e164 VARCHAR(20) UNIQUE`, `display_name VARCHAR(100) NOT NULL`, `avatar_url VARCHAR(500)`, `password_hash VARCHAR(255) NOT NULL`, `discoverable BOOLEAN NOT NULL DEFAULT TRUE`, `allow_messages_from_non_contacts BOOLEAN NOT NULL DEFAULT TRUE`, `status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE'`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `deleted_at TIMESTAMPTZ`. Ràng buộc: `chk_users_status CHECK (status IN ('ACTIVE', 'LOCKED', 'DELETED'))`, `chk_users_phone_format CHECK (phone_e164 IS NULL OR phone_e164 ~ '^\+[1-9][0-9]{7,14}$')`.
   - **`user_devices`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `device_id_hash VARCHAR(64) NOT NULL`, `device_name VARCHAR(100)`, `platform VARCHAR(20) NOT NULL DEFAULT 'ANDROID'`, `trusted BOOLEAN NOT NULL DEFAULT FALSE`, `token_valid_after TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `last_seen_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `revoked_at TIMESTAMPTZ`, `CONSTRAINT uq_user_device UNIQUE (user_id, device_id_hash)`.
   - **`otp_challenges`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `phone_e164 VARCHAR(20) NOT NULL`, `purpose VARCHAR(20) NOT NULL CHECK (purpose IN ('REGISTER', 'LOGIN', 'PASSWORD_RESET'))`, `device_id_hash VARCHAR(64) NOT NULL`, `code_hash VARCHAR(64) NOT NULL`, `attempts INT NOT NULL DEFAULT 0`, `expires_at TIMESTAMPTZ NOT NULL`, `consumed_at TIMESTAMPTZ`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
   - **`auth_sessions`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `user_id UUID REFERENCES users(id) ON DELETE CASCADE`, `device_id_hash VARCHAR(64) NOT NULL`, `method VARCHAR(20) NOT NULL CHECK (method IN ('PASSWORD', 'OTP', 'RESET'))`, `state VARCHAR(20) NOT NULL CHECK (state IN ('NEED_OTP', 'COMPLETE', 'FAILED', 'LOCKED'))`, `expires_at TIMESTAMPTZ NOT NULL`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
   - **`auth_throttles`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `scope_type VARCHAR(20) NOT NULL CHECK (scope_type IN ('PHONE', 'DEVICE', 'PHONE_DEVICE'))`, `scope_key_hash VARCHAR(64) NOT NULL`, `purpose VARCHAR(20) NOT NULL CHECK (purpose IN ('PASSWORD_LOGIN', 'OTP_VERIFY', 'PASSWORD_RESET'))`, `failure_count INT NOT NULL DEFAULT 0`, `window_started_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `locked_until TIMESTAMPTZ`, `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `CONSTRAINT uq_auth_throttles_scope UNIQUE (scope_type, scope_key_hash, purpose)`.
   - **`contact_requests`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `requester_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `addressee_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `status VARCHAR(20) NOT NULL DEFAULT 'PENDING' CHECK (status IN ('PENDING', 'ACCEPTED', 'REJECTED', 'CANCELED'))`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `responded_at TIMESTAMPTZ`, `CONSTRAINT chk_contact_requests_no_self CHECK (requester_id <> addressee_id)`.
   - **`contacts`**: `owner_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `contact_user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `blocked BOOLEAN NOT NULL DEFAULT FALSE`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `CONSTRAINT pk_contacts PRIMARY KEY (owner_id, contact_user_id)`, `CONSTRAINT chk_contacts_no_self CHECK (owner_id <> contact_user_id)`.
   - **`conversations`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `type VARCHAR(20) NOT NULL CHECK (type IN ('DIRECT', 'GROUP'))`, `title VARCHAR(100)`, `avatar_url VARCHAR(500)`, `direct_key VARCHAR(100) UNIQUE`, `created_by UUID REFERENCES users(id) ON DELETE SET NULL`, `last_message_id BIGINT`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
   - **`conversation_members`**: `conversation_id UUID NOT NULL REFERENCES conversations(id) ON DELETE CASCADE`, `user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `role VARCHAR(20) NOT NULL DEFAULT 'MEMBER' CHECK (role IN ('ADMIN', 'MEMBER'))`, `visible_from_message_id BIGINT NOT NULL DEFAULT 0`, `last_delivered_message_id BIGINT NOT NULL DEFAULT 0`, `last_read_message_id BIGINT NOT NULL DEFAULT 0`, `muted BOOLEAN NOT NULL DEFAULT FALSE`, `joined_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `left_at TIMESTAMPTZ`, `CONSTRAINT pk_conversation_members PRIMARY KEY (conversation_id, user_id)`, `CONSTRAINT chk_watermarks_monotonic CHECK (last_delivered_message_id >= last_read_message_id)`.
   - **`attachments`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `uploader_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `kind VARCHAR(20) NOT NULL CHECK (kind IN ('IMAGE', 'AUDIO', 'VIDEO', 'FILE'))`, `mime VARCHAR(100) NOT NULL`, `size_bytes BIGINT NOT NULL`, `storage_path VARCHAR(500) NOT NULL`, `original_name VARCHAR(255)`, `duration_ms INT`, `width INT`, `height INT`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
   - **`calls`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `conversation_id UUID NOT NULL REFERENCES conversations(id) ON DELETE CASCADE`, `caller_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `callee_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `media VARCHAR(20) NOT NULL DEFAULT 'VOICE' CHECK (media = 'VOICE')`, `state VARCHAR(20) NOT NULL DEFAULT 'RINGING' CHECK (state IN ('RINGING', 'ACTIVE', 'ENDED', 'MISSED', 'REJECTED', 'BUSY', 'FAILED'))`, `end_reason VARCHAR(20) CHECK (end_reason IS NULL OR end_reason IN ('HANGUP', 'TIMEOUT', 'REJECT', 'BUSY', 'OFFLINE', 'ERROR'))`, `started_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `answered_at TIMESTAMPTZ`, `ended_at TIMESTAMPTZ`.
   - **`messages`**: `id BIGSERIAL PRIMARY KEY`, `conversation_id UUID NOT NULL REFERENCES conversations(id) ON DELETE CASCADE`, `sender_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `client_id UUID NOT NULL`, `type VARCHAR(20) NOT NULL CHECK (type IN ('TEXT', 'IMAGE', 'AUDIO', 'VIDEO', 'FILE', 'LOCATION', 'SYSTEM', 'CALL'))`, `text VARCHAR(4000)`, `attachment_id UUID REFERENCES attachments(id) ON DELETE SET NULL`, `call_id UUID REFERENCES calls(id) ON DELETE SET NULL`, `system_event VARCHAR(50)`, `system_params TEXT`, `latitude DOUBLE PRECISION`, `longitude DOUBLE PRECISION`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `CONSTRAINT uq_messages_client UNIQUE (sender_id, client_id)`.
   - **`sync_events`**: `id BIGSERIAL PRIMARY KEY`, `user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `event_type VARCHAR(50) NOT NULL CHECK (event_type IN ('MESSAGE_CREATED', 'CONVERSATION_UPDATED', 'CONTACT_REQUEST_CREATED', 'CONTACT_REQUEST_UPDATED', 'CONTACT_UPDATED', 'RECEIPT_UPDATED', 'CALL_UPDATED', 'DEVICE_REVOKED'))`, `entity_type VARCHAR(50) NOT NULL CHECK (entity_type IN ('MESSAGE', 'CONVERSATION', 'CONTACT_REQUEST', 'CONTACT', 'RECEIPT', 'CALL', 'DEVICE'))`, `entity_id VARCHAR(100) NOT NULL`, `payload_json JSONB NOT NULL`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.
   - **`demo_sms_outbox`**: `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`, `phone_e164 VARCHAR(20) NOT NULL`, `body TEXT NOT NULL`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`.

### Task 01-02-02: Bổ sung chỉ mục hiệu năng cao và kích hoạt RLS Lockdown trong Flyway migration

<read_first>
- `C:/Users/Admin/Desktop/Project-Mobile/docs/ERD.md` (Mục 2.2, 2.4, 3)
- `C:/Users/Admin/Desktop/Project-Mobile/docs/ARCHITECTURE_DECISIONS.md` (ADR-007, ADR-010, ADR-016)

<action>
1. Mở tệp `backend/src/main/resources/db/migration/V1__initial_schema.sql` và bổ sung các chỉ mục B-tree, Partial Unique Index vào cuối từng bảng hoặc khối chỉ mục chuyên dụng:
   ```sql
   -- Chỉ mục tối ưu tra cứu số điện thoại
   CREATE INDEX idx_users_phone ON users(phone_e164) WHERE phone_e164 IS NOT NULL;
   CREATE INDEX idx_user_devices_user ON user_devices(user_id);
   CREATE INDEX idx_otp_challenges_phone_created ON otp_challenges(phone_e164, created_at DESC);

   -- Bất biến chống tạo lời mời ngược chiều khi đang PENDING (ADR-020, docs/ERD.md mục 2.2)
   CREATE UNIQUE INDEX idx_contact_requests_pending_pair 
   ON contact_requests (LEAST(requester_id, addressee_id), GREATEST(requester_id, addressee_id)) 
   WHERE status = 'PENDING';

   CREATE INDEX idx_contact_requests_addressee ON contact_requests(addressee_id, status);
   CREATE INDEX idx_contact_requests_requester ON contact_requests(requester_id, status);

   CREATE INDEX idx_contacts_owner_blocked ON contacts(owner_id, blocked);
   CREATE INDEX idx_contacts_target ON contacts(contact_user_id);

   CREATE INDEX idx_conversations_last_msg ON conversations(last_message_id DESC NULLS LAST);
   CREATE INDEX idx_conv_members_user ON conversation_members(user_id) WHERE left_at IS NULL;

   CREATE INDEX idx_attachments_uploader ON attachments(uploader_id);

   CREATE INDEX idx_calls_conversation ON calls(conversation_id, started_at DESC);
   CREATE INDEX idx_calls_caller ON calls(caller_id);
   CREATE INDEX idx_calls_callee ON calls(callee_id);

   -- Chỉ mục tối ưu phân trang lịch sử tin nhắn tốc độ cao (docs/ERD.md mục 2.4)
   CREATE INDEX idx_messages_conversation_id_desc ON messages (conversation_id, id DESC);

   -- Chỉ mục tối ưu con trỏ đồng bộ bù sync_events (docs/ERD.md mục 2.4)
   CREATE INDEX idx_sync_events_user_cursor ON sync_events (user_id, id);
   CREATE INDEX idx_sync_events_created ON sync_events (created_at);

   CREATE INDEX idx_demo_sms_phone_created ON demo_sms_outbox(phone_e164, created_at DESC);
   ```

2. Bổ sung khối kích hoạt Row Level Security (RLS) trên toàn bộ 14 bảng:
   ```sql
   -- =============================================================================
   -- Row Level Security (RLS) Lockdown (ADR-007)
   -- Default Deny on all tables. NO POLICIES CREATED.
   -- Blocks PostgREST public API completely (anon / authenticated).
   -- Backend connects via 'postgres' role with BYPASSRLS.
   -- =============================================================================

   ALTER TABLE users ENABLE ROW LEVEL SECURITY;
   ALTER TABLE user_devices ENABLE ROW LEVEL SECURITY;
   ALTER TABLE otp_challenges ENABLE ROW LEVEL SECURITY;
   ALTER TABLE auth_sessions ENABLE ROW LEVEL SECURITY;
   ALTER TABLE auth_throttles ENABLE ROW LEVEL SECURITY;
   ALTER TABLE contact_requests ENABLE ROW LEVEL SECURITY;
   ALTER TABLE contacts ENABLE ROW LEVEL SECURITY;
   ALTER TABLE conversations ENABLE ROW LEVEL SECURITY;
   ALTER TABLE conversation_members ENABLE ROW LEVEL SECURITY;
   ALTER TABLE attachments ENABLE ROW LEVEL SECURITY;
   ALTER TABLE calls ENABLE ROW LEVEL SECURITY;
   ALTER TABLE messages ENABLE ROW LEVEL SECURITY;
   ALTER TABLE sync_events ENABLE ROW LEVEL SECURITY;
   ALTER TABLE demo_sms_outbox ENABLE ROW LEVEL SECURITY;
   ```
   **TUYỆT ĐỐI KHÔNG TẠO BẤT KỲ `CREATE POLICY` NÀO VÀ KHÔNG SỬ DỤNG `FORCE ROW LEVEL SECURITY`.**
</action>

<acceptance_criteria>
- Tệp `V1__initial_schema.sql` chứa đầy đủ các chỉ mục B-tree, bao gồm `idx_contact_requests_pending_pair`, `idx_messages_conversation_id_desc`, và `idx_sync_events_user_cursor`.
- Lệnh `ENABLE ROW LEVEL SECURITY` được áp dụng cho toàn bộ 14 bảng (`users`, `user_devices`, `otp_challenges`, `auth_sessions`, `auth_throttles`, `contact_requests`, `contacts`, `conversations`, `conversation_members`, `attachments`, `calls`, `messages`, `sync_events`, `demo_sms_outbox`).
- Không có bất kỳ lệnh `CREATE POLICY` hay `FORCE ROW LEVEL SECURITY` nào xuất hiện trong tệp.
</acceptance_criteria>

<verify>
<automated>
powershell -ExecutionPolicy Bypass -Command "if ((Select-String -Path backend/src/main/resources/db/migration/V1__initial_schema.sql -Pattern 'idx_contact_requests_pending_pair' -Quiet) -and (Select-String -Path backend/src/main/resources/db/migration/V1__initial_schema.sql -Pattern 'idx_messages_conversation_id_desc' -Quiet) -and (Select-String -Path backend/src/main/resources/db/migration/V1__initial_schema.sql -Pattern 'idx_sync_events_user_cursor' -Quiet) -and ((Select-String -Path backend/src/main/resources/db/migration/V1__initial_schema.sql -Pattern 'ENABLE ROW LEVEL SECURITY').Count -ge 14) -and -not (Select-String -Path backend/src/main/resources/db/migration/V1__initial_schema.sql -Pattern 'CREATE POLICY' -Quiet)) { Write-Output 'PASS: Indexes and RLS lockdown configured properly'; exit 0 } else { Write-Error 'FAIL: Missing indexes or invalid RLS lockdown configuration'; exit 1 }"
</automated>

</fails_when>
</verify>
