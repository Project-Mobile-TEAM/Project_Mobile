## Prohibition Recall Breadcrumb
Canon OWASP security items (JWT query-param rejection, SQL injection, IDOR/RBAC actor extraction from `AuthenticatedActor`, PII phone hiding on non-friends) are delegated to `<threat_model>` below; kept domain-specific prohibitions appear in `must_haves.prohibitions`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted Android client -> Backend REST Controllers | Caller supplies conversation UUIDs, message `clientId`, `text`, `type`, query params; identity MUST come solely from `@AuthenticationPrincipal AuthenticatedActor`. |
| Backend JDBC -> Supabase Public Schema (`V5`) | Any new PostgreSQL table (`sync_retention_state`) sits in `public` schema exposed to Supabase PostgREST unless RLS default-deny is enabled. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Spoofing / Tampering | `MessageController`, `ConversationController` | high | mitigate | Extract `actor.userId()` exclusively from `@AuthenticationPrincipal AuthenticatedActor`; reject `type != "TEXT"` (especially `SYSTEM`) and missing/invalid UUIDs with `400 VALIDATION` / `404 NOT_FOUND`. |
| T-05-02 | Elevation of Privilege / Privacy Bypass | `ConversationService.openOrCreateDirect`, `MessageService.sendMessage` | high | mitigate | Call `ContactPolicyService.lockPair(actor, peer)` + `isBlockedEitherWay` (`403 BLOCKED`) strictly before `allow_messages_from_non_contacts` / `areAcceptedFriends` (`403 CONTACT_REQUIRED`), and verify active `conversation_members` (`left_at IS NULL` -> `403 NOT_A_MEMBER`). |
| T-05-03 | Tampering / Data Loss | `V5__sync_and_messaging.sql`, `sync_retention_state` | high | mitigate | Enable `ALTER TABLE public.sync_retention_state ENABLE ROW LEVEL SECURITY;` with zero policies (ADR-007 default deny); enforce `barrier_xid` via PostgreSQL `BEFORE INSERT` trigger so no app code can bypass it. |
| T-05-04 | Denial of Service | `MessageRateLimiter` | medium | mitigate | Sliding-window log enforcing max 30 messages / 10 seconds / `userId` (`429 RATE_LIMITED` + `retryAfterSeconds`) using injectable UTC `Clock`. |
</threat_model>
