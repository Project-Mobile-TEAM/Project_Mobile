<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Synced `MessageEntity` (`attachmentJson`, `type`) -> `MessageAdapter` | Server or seed messages may carry Phase 6 non-TEXT types (`IMAGE`, `AUDIO`, `VIDEO`, `FILE`, `LOCATION`, `CALL`) or future unknown types. |
| `ChatRoomFragment` lifecycle -> `POST /conversations/{id}/read` | Backgrounded/paused UI must not silently mark unseen messages as `READ`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-23 | Tampering / Availability | `MessageAdapter`, `SystemMessageFormatter` | medium | mitigate | Handle unknown `type` via `UNKNOWN_FALLBACK` view type and null/malformed `attachmentJson` gracefully without crashes; attach zero external-app/file-open/call click intents on non-TEXT summary cards in Phase 5. |
| T-05-24 | Repudiation / False Read State | `ChatRoomFragment.onResume`, `ChatRoomViewModel.markVisibleRead` | low | mitigate | Gate `markConversationRead` strictly behind `isResumed()` state and monotonically increasing visibleUpToServerId > myMember.getLastReadId(); never acknowledge loaded-but-unseen rows. |
</threat_model>
