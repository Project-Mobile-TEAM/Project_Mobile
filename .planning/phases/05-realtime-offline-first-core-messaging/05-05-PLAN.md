<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote WebSocket / REST responses -> Room SQLite Cache | Late HTTP/WS responses from a prior account/session or out-of-order group history could corrupt current user's Room cache. |
| Android SessionManager -> OkHttp WS / REST clients | Bearer token must only travel to `BuildConfig.BACKEND_BASE_URL` host in `Authorization` header, never in URLs or logs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-15 | Information Disclosure | `ChatWebSocketManager`, `ApiClient`, `AuthInterceptor` | critical | mitigate | Derive WS URL solely from `BuildConfig.BACKEND_BASE_URL` (`https->wss`, `http->ws`, `/ws`); pass JWT solely via `.header("Authorization", "Bearer " + token)` without URL params; preserve `HttpLoggingInterceptor.Level.NONE` in Release. |
| T-05-16 | Spoofing / Cross-Account Leak | `SessionManager`, `SyncEngine`, `SyncEventApplier` | high | mitigate | Capture `sessionKey` (`generation:userId`) before every network call; run Room writes via `session.runIfCurrent(key, ...)` on `DISK`; handle `4401`/`auth.revoked`/`401` by clearing matching session only and firing `SessionEvents.notifyExpired()`. |
| T-05-17 | Tampering / History Exposure | `SyncEventApplier`, `SyncEngine` | high | mitigate | Enforce `MessageDao.insertRespectingVisibleFrom` and `ConversationDao.upsertMemberMonotonic`; purge `serverId <= newVisible` in same transaction; keep `lastSyncEventId` untouched on WS frames and never skip Contact events. |
</threat_model>
